# Third-party software

This workspace incorporates or interfaces with software from AgileX Robotics,
Orbbec, VAMP, HGGD-MCU, EdgeSAM, ONNX Runtime, PyTorch, OpenCV, PCL, Eigen,
OctoMap, and their transitive dependencies. Original license and provenance
files are retained beside bundled source and model assets.

Before redistribution, review the license files in each package and model
directory. The optional AnyPlace checkpoint is downloaded separately and is
not part of this repository.
